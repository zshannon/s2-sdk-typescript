    Type Alias PkiAuthConfig

    Configuration for PKI authentication.

    Two modes are supported:

    1. Token + SigningKey mode (for regular operations): Provide token and signingKey. Use this for basins, streams, and other regular operations.

    2. Root key mode (for all operations): Provide only rootKey. The SDK generates tokens locally (signed by root key, bound to a generated client key).
